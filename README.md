# AfriLearn 🎓

> L'écosystème numérique conçu pour les étudiants et entreprises d'Afrique francophone.

## 🚀 Déploiement rapide sur Vercel

### 1. Cloner / uploader ce projet sur GitHub
- Crée un repo GitHub nommé `afrilearn`
- Upload tous ces fichiers dedans

### 2. Déployer sur Vercel
- Va sur [vercel.com](https://vercel.com)
- "Add New Project" → connecte ton GitHub
- Sélectionne le repo `afrilearn`
- Framework : **Create React App**
- Clique **Deploy** ✅

### 3. Accès aux espaces

| Espace | URL |
|--------|-----|
| Application principale | `https://afrilearn.vercel.app` |
| Panel Admin (Fondateur) | `https://afrilearn.vercel.app?admin` |

---

## 📱 Fonctionnalités

### Espace Étudiant
- ✅ Onboarding sécurisé avec vérification de documents
- ✅ Assistant IA spécialisé Afrique francophone
- ✅ Communauté : posts, partage de cours, photos, fichiers
- ✅ Messagerie privée chiffrée
- ✅ Stages & emplois avec score de compatibilité IA
- ✅ Système de candidature complet (CV + lettre)

### Espace Entreprise
- ✅ Vérification RCCM obligatoire
- ✅ Publication d'offres de stage/emploi
- ✅ Gestion des candidatures avec score IA
- ✅ Dashboard statistiques

### Panel Fondateur (Admin)
- ✅ Code PIN sécurisé
- ✅ KPIs et revenus en temps réel
- ✅ Gestion utilisateurs (suspension, bannissement, vérification)
- ✅ Gestion des plaintes par priorité
- ✅ File de vérification des documents
- ✅ Gestion des mises à jour
- ✅ Analytics détaillées

## 💰 Modèle économique

- Abonnements Premium étudiants (~2-3$/mois)
- Publication d'offres pour entreprises
- Publicité ciblée partenaires
- Micro-certifications IA

## 🛠️ Stack technique

- **Frontend** : React 18
- **IA** : Anthropic Claude API
- **Hébergement** : Vercel
- **Prochain** : Supabase (base de données + auth réelle)
